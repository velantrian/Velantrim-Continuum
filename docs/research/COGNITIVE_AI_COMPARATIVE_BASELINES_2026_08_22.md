**Status:** RESEARCH COMPARISON ONLY · DOCS ONLY · NO PILOT / RUNTIME / INTEGRATION AUTHORITY

## Purpose

Record external memory/context and developmental-cognition systems only as comparative baselines for Continuum's core question:

> What explicit durable process state is sufficient for functional continuation after the current inference/context/runtime disappears?

This note does not adopt any external architecture and does not change Experiment 0, Pilot, Evidence Lock, Gold/Oracle, runtime or production status.

## MemGPT / Letta

Useful comparative baseline for:

- tiered memory;
- persistent agent state;
- context-window management;
- reattachment of inference to durable state.

Continuum's research question is stricter and different:

```text
context extension != functional continuity
persistent memory != identity continuity
handoff success != hidden-state reconstruction
agent state storage != proof of sufficient process state
```

A MemGPT/Letta-style mechanism may be compared against Continuum Capture/Transfer arms only if the comparison is preregistered and does not alter approved reference semantics.

## Comparative evaluation dimensions

Any future comparison should distinguish at least:

- goal retention;
- task-position retention;
- decision and rationale retention;
- constraint/prohibition retention;
- blocker/open-loop retention;
- provenance/reference retention;
- obsolete-state carryover;
- hallucinated-state rate;
- handoff size/context efficiency;
- successor task-continuation success;
- causal freshness;
- transactional state correctness where applicable.

## Research boundary

External systems are baselines, not architecture choices. A simpler explicit state representation may remain superior if it preserves continuity with lower complexity and stronger auditability.
